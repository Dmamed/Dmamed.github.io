Cómo usar LogicForge

  • 1. Elige un tipo de argumento: Selecciona una plantilla del menú. Las premisas y conclusión se rellenarán automáticamente. También puedes usar 'Personalizado'.
  • 2. Edita las premisas y conclusión: Escribe fórmulas lógicas con →, ¬, ∧, ∨, ↔ (o ->, !, &, |, <->).
  • 3. Añade o elimina premisas: Usa los botones para ajustar el número de premisas (S₁, S₂, S₃...).
  • 4. Asigna criterios: En el panel izquierdo (Glosario), escribe el significado de cada variable (ej. P = 'Llueve').
  • 5. Valida, exporta o comparte: Usa los botones inferiores para verificar la validez, copiar en Markdown/LaTeX, exportar a PDF o compartir por URL.
